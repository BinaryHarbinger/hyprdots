General Management:
- SUPER + V           Toggle floating mode for the active window
- SUPER + C           Close (kill) the active window
- SUPER + M           Toggle pseudo-tile layout (Dwindle mode)
- SUPER + H           Swap split orientation (Dwindle mode)
- SUPER + J           Toggle split layout (Dwindle mode)
- SUPER + F           Toggle fullscreen

Moving Focus:
- SUPER + ←           Move focus left
- SUPER + →           Move focus right
- SUPER + ↑           Move focus up
- SUPER + ↓           Move focus down

Workspace Switching:
- SUPER + 1..0        Switch to workspace 1–10
- SUPER + Scroll↓     Next workspace
- SUPER + Scroll↑     Previous workspace

Move Active Window to Workspaces:
- SUPER + SHIFT + 1..0      Move active window to workspace 1–10
- ALT + TAB                 Switch to next workspace

Move/Resize Windows:
- SUPER + Left Click        Move window
- SUPER + Right Click       Resize window
- SUPER + SHIFT + ↑         Resize active window (shrink vertically)
- SUPER + SHIFT + →         Resize active window (grow horizontally)
- SUPER + SHIFT + ↓         Resize active window (grow vertically)
- SUPER + SHIFT + ←         Resize active window (shrink horizontally)

Volume and Media Control:
- XF86AudioRaiseVolume      Increase volume (+10)
- XF86AudioLowerVolume      Decrease volume (-10)
- XF86AudioMicMute          Toggle microphone mute
- XF86AudioMute             Toggle audio mute
- XF86AudioPlay             Play/Pause media
- XF86AudioStop             Stop media
- XF86AudioPause            Play/Pause media
- XF86AudioNext             Next track
- XF86AudioPrev             Previous track
- XF86MonBrightnessUp       Increase screen brightness (+10%)
- XF86MonBrightnessDown     Decrease screen brightness (-10%)
- XF86KbdBrightnessUp       Increase keyboard backlight
- XF86KbdBrightnessDown     Decrease keyboard backlight
- XF86KbdLightOnOff         Toggle keyboard backlight

Applications:
- SUPER + I           Reload Waybar, Eww, and SwayNC
- SUPER + N           Launch editor ($editor)
- SUPER + T           Launch terminal ($terminal)
- SUPER + E           Launch file manager ($fileManager)
- File Explorer       Launch file manager ($fileManager)
- SUPER + B           Launch browser ($browser)
- SUPER + P           Launch music player ($musicPlayer)

Rofi Menus:
- SUPER + TAB         Open window switcher (Rofi)
- SUPER + Q           Open menu (Rofi)
- SUPER + S           Open $menu
- SUPER + R           Open $rmenu
- SUPER + X           Open clipboard menu

Utilities:
- SUPER + O                    Launch picker script
- SUPER + L                    Launch logout menu
- SUPER + Print                Screenshot full screen (hyprshot)
- SUPER + SHIFT + Print        Screenshot region (hyprshot)
- SUPER + K                    Launch scrcpy
- SUPER + U                    Open system menu (Rofi)
- XF86Tools                    Open system menu (Rofi)
- SUPER + =                    Open rofimoji
- Escape                       Close action center, widgets, and Rofi
